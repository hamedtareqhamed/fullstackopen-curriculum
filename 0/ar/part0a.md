# معلومات عامة

مرحباً بك في دورة **Full Stack Open**.

تهدف هذه الدورة إلى تدريبك على تطوير تطبيقات الويب الحديثة باستخدام تقنيات جافاسكريبت المتقدمة مثل React و Node.js و Express و MongoDB و GraphQL و TypeScript.

### المتطلبات الأساسية
- معرفة أساسية بمبادئ البرمجة وتراكيب البيانات.
- فهم مبسط لكيفية عمل الويب وHTML وCSS.
- الرغبة في التعلّم الذاتي والبحث وحل المشكلات البرمجية.

### بيئة التطوير
- متصفح ويب حديث مثل Chrome أو Firefox مع أدوات المطورين (DevTools).
- محرر نصوص قوي ومناسب لكتابة الكود مثل Visual Studio Code.
- تثبيت Node.js و Git على جهازك.
