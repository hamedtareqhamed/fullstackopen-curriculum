# Full Stack Open - Curriculum Repository (مستودع المنهج التعليمي)

يحتوي هذا المستودع على كافة المواد التعليمية وملفات الشروحات (Markdown) والترجمات والصور التوضيحية لدورة **Full Stack Open**.

---

## هيكلية المستودع (Directory Structure)

```
fullstackopen-curriculum/
├── 0/ .. 14/                # أجزاء المنهج التعليمي (الأجزاء من 0 إلى 14)
│   ├── en/                  # النسخة الإنجليزية
│   ├── fi/                  # النسخة الفنلندية
│   ├── es/                  # النسخة الإسبانية
│   ├── fr/                  # النسخة الفرنسية
│   ├── zh/                  # النسخة الصينية
│   └── ptbr/                # النسخة البرتغالية (البرازيل)
├── assets/                  # ملفات وأصول إضافية تابعة للمنهج
├── images/                  # الصور والرسوم البيانية التوضيحية للشروحات وأيقونات الأجزاء
├── pages/                   # محتوى ونصوص الصفحات الثابتة (about, faq, stories, main)
├── partnavigation/          # بيانات هيكلة وفهرسة الأجزاء والتنقل بينها
├── seo/                     # نصوص محركات البحث والكلمات المفتاحية
├── CONTRIBUTING.md           # دليل المساهمة في تعديل المنهج
├── Translate.md             # إرشادات المساهمة في الترجمة
└── LICENSE                  # ترخيص المحتوى (Creative Commons BY-NC-SA 3.0)
```
