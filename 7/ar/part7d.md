بالإضافة إلى التمارين الستة في أقسام خطافات React السابقة، تحتوي هذه السلسلة على 14 تمريناً لتطوير وتوسيع تطبيق قائمة المدونات (BlogList) الذي بنيناه في الجزأين الرابع والخامس، مع تطبيق مفاهيم إدارة الحالة المتقدمة (Zustand أو React Query و Context)، وإعادة الهيكلة الشاملة (Refactoring).

<h3>التمارين 7.7 - 7.20: توسيع وتطوير تطبيق قائمة المدونات</h3>

<h4>7.7: الواجهة والخادم في مستودع موحد (Frontend and backend in the same repo)</h4>
أعد هيكلة مشروع المدونات بحيث يضم الواجهة الأمامية (`client/`) والخادم الخلفي (`server/`) في مستودع موحد (Monorepo) مع ضبط أوامر التشغيل عبر `concurrently`.

<h4>7.8: حدود الأخطاء (Error boundary)</h4>
أضف مكوّن حدود الأخطاء `ErrorBoundary` للتطبيق بحيث يغلف جسم التطبيق (دون شريط التنقل العلوي) لعرض واجهة بديلة ودية في حال حدوث أي استثناء أو خطأ تصيير.

![واجهة اصطياد الخطأ](../../images/7/b1.png)

<h4>7.9: مسارات الصفحات غير الموجودة (Nonexisting routes)</h4>
اضبط مسار النجمة `path="*"` في React Router لعرض رسالة تفيد بأن "الصفحة غير موجودة" (Page Not Found - 404) بدلاً من ظهور صفحة بيضاء فارغة.

![صفحة غير موجودة](../../images/7/b4.png)

<h4>7.10: التنسيق التلقائي للشيفرة مع Prettier</h4>
ثبت وهيئ أداة **Prettier** في محرر الأكواد لتنسيق ملفات المشروع تلقائياً عند كل عملية حفظ (Format on Save).

---

### إدارة الحالة: خيار Zustand (أو خيار React Query و Context)

<i>يمكنك اختيار تطبيق التمارين 7.11 إلى 7.14 باستخدام Zustand أو باستخدام React Query و Context:</i>

<h4>7.11: إدارة الإشعارات (Notifications State)</h4>
أعد هيكلة رسائل التنبيه في تطبيق المدونات لتدار عبر مخزن Zustand (أو عبر useReducer و React Context).

<h4>7.12: إدارة قائمة المدونات (Blogs State)</h4>
انقل حالة المدونات وعملية إنشاء مدونة جديدة إلى مخزن Zustand (أو عبر React Query).

<h4>7.13: تفعيل الإعجاب والحذف (Like and Delete blogs)</h4>
قم بتفعيل عمليات زيادة الإعجابات وحذف المدونات باستخدام المخزن المركزي (Zustand أو React Query Mutations).

<h4>7.14: إدارة بيانات المستخدم المسجل (Logged-in User State)</h4>
خزن بيانات وحالة المستخدم المسجل حالياً في المخزن المركزي (Zustand أو Context API).

---

<h4>7.15: تنظيف الكود وعزل التخزين المحلي (Cleaning the code)</h4>
اعزل كافة عمليات التعامل مع `window.localStorage` داخل وحدة خدمة مستقلة `src/services/persistentUser.js`، واستخدم الخطاف المخصص `useField` في نماذج الإدخال.

<h4>7.16: صفحة المستخدمين (Users view)</h4>
أضف صفحة جديدة تعرض جدولاً بجميع المستخدمين المسجلين في النظام مع عدد المدونات التي أنشأها كل مستخدم.

![جدول المستخدمين](../../images/7/b5.png)

<h4>7.17: صفحة المستخدم الفردية (Individual User view)</h4>
أضف صفحة تفصيلية تعرض قائمة بجميع المدونات المضافة من قِبل مستخدم محدد عند النقر على اسمه في جدول المستخدمين.

![مدونات المستخدم المختار](../../images/7/b6.png)

<h4>7.18: التعليقات على المدونات - الخطوة 1 (Comments step 1)</h4>
أضف ميزة التعليقات على المدونات في الخادم والواجهة بحيث تظهر التعليقات المجهولة أسفل كل مدونة.

![قائمة التعليقات](../../images/7/u8.png)

<h4>7.19: التعليقات على المدونات - الخطوة 2 (Comments step 2)</h4>
أضف نموذجاً في الواجهة الأمامية يتيح للزوار كتابة وإرسال تعليق جديد على المدونة وتحديث القائمة فورياً.

![إضافة تعليق](../../images/7/u9.png)

<h4>7.20: التنسيق الجمالي والتصميم (Styling)</h4>
قم بتحسين المظهر المرئي لواجهة تطبيق المدونات باستخدام إحدى أطر العمل (مثل React Bootstrap، أو Material UI، أو Tailwind CSS، أو Styled Components).

هذا هو التمرين الأخير في الجزء السابع. ارفع الحلول إلى مستودع GitHub وسجل إنجازك في نظام المتابعة.
