<div class="intro">

سنتعرف في هذا الجزء على إطار العمل **[Next.js](https://nextjs.org/)**، وهو إطار العمل الرائد لتطبيقات React المتكاملة (Full Stack React Framework) والمبني على معمارية تصيير الخادم **(Server-Side Rendering - SSR)** ومكونات خادم ريأكت **(React Server Components - RSC)** ونظام التوجيه القائم على مجلدات التطبيق **(App Router)**.

تتوفر المادة التفاعلية الكاملة لهذا الجزء عبر منصة MOOC المفتوحة لجامعة هلسنكي:
<a href="https://courses.mooc.fi/org/uh-cs/courses/full-stack-open-nextjs">https://courses.mooc.fi/org/uh-cs/courses/full-stack-open-nextjs</a>

يغطي هذا الجزء:
- بناء التطبيقات بمعمارية App Router و Server Components.
- تصيير الصفحات الثابتة والتوليد المسبق (Static Site Generation - SSG).
- إجراءات الخادم (Server Actions) لجلب وتعديل البيانات مباشرة دون الحاجة لطبقة REST API وسيطة.
- تحسين محركات البحث (SEO) وأداء الويب ومقاييس Core Web Vitals.
