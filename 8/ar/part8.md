<div class="intro">

سنتعلم في هذا الجزء كيفية استخدام لغة الاستعلام **GraphQL** كبديل حديث وقوي لواجهات REST API التقليدية.

تتيح GraphQL للعميل (المتصفح أو تطبيق الهاتف) تحديد بنية وشكل البيانات التي يريد استلامها بدقة بالغة في طلب واحد، مما يقضي تماماً على مشاكل جلب البيانات الزائدة (Over-fetching) أو جلب البيانات الناقصة (Under-fetching).

سنغطي في هذا الجزء:
- بناء خادم GraphQL متكامل باستخدام **Apollo Server**.
- كتابة المخططات (Schemas)، والاستعلامات (Queries)، والطفرات (Mutations).
- ربط React بخادم GraphQL عبر **Apollo Client**.
- إدارة قواعد البيانات والمستخدمين والمصادقة بالرموز المميزة (JWT).
- التحديث الفوري المباشر عبر الاشتراكات والويب سوكت **GraphQL Subscriptions & WebSockets**.
