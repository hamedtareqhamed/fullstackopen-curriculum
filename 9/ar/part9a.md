تُعد **[TypeScript](https://www.typescriptlang.org/)** لغة برمجة طورتها شركة Microsoft لتلبية احتياجات بناء وصيانة تطبيقات JavaScript الضخمة والمعقدة (مثل محرر VS Code وبوابة Azure).

---

### المبدأ الأساسي: مجموعة شاملة موسعة (Superset of JavaScript)

تُعد TypeScript مجموعة شاملة موسعة من JavaScript، مما يعني أن كل شيفرة JavaScript قياسية هي شيفرة TypeScript صالحة تلقائياً.

تتألف TypeScript من ثلاثة عناصر رئيسية:
1. **اللغة (The Language)**: الصيغة والكلمات المفتاحية وإعلانات الأنواع (Type Annotations).
2. **المُصرّف (The Compiler - `tsc`)**: المسؤول عن التحقق الثابت من الأنواع ثم **محو معلومات الأنواع (Type Erasure)** وترجمة الكود إلى JavaScript قياسي قابل للتنفيذ في أي متصفح أو بيئة Node.js.
3. **خدمة اللغة (The Language Service)**: توفر أدوات الإكمال التلقائي الذكي (IntelliSense)، وتلميحات الأنواع، وإعادة الهيكلة الفورية (Refactoring) داخل محررات الأكواد.

### الخصائص الجوهرية للغة TypeScript

#### 1. إعلانات الأنواع (Type Annotations)
تحدد "العقد البرمجي" الدقيق لمعاملات الدوال وقيم الإرجاع والمتغيرات:

```ts
const birthdayGreeter = (name: string, age: number): string => {
  return `عيد ميلاد سعيد يا ${name}، لقد بلغت الآن ${age} عاماً!`
}
```

#### 2. الاستنتاج التلقائي للأنواع (Type Inference)
يستطيع مصرف TypeScript استنتاج نوع المتغير أو ناتج الدالة تلقائياً من خلال القيمة الابتدائية وسياق الاستخدام دون الحاجة لكتابتها يدوياً:

```ts
const add = (a: number, b: number) => {
  return a + b // يستنتج المترجم تلقائياً أن ناتج الدالة هو number
}
```

#### 3. نظام الأنواع الهيكلي (Structural Typing)
يعتمد توافق الأنواع في TypeScript على **هيكل الكائن ومحتوياته** وليس على اسمه أو تصريحه الصريح (Duck Typing: "إذا كان يسير كالبطة ويصدر صوت البطة فهو بطة").

#### 4. محو الأنواع أثناء الترجمة (Type Erasure)
تُحذف كافة تصريحات وأنواع TypeScript تماماً أثناء عملية التصريف والترجمة، بحيث لا يتبقى في ملفات JavaScript الناتجة أي أثر لأنظمة الأنواع في وقت التشغيل (Runtime).

---

### لماذا نستخدم TypeScript؟

- **اكتشاف الأخطاء مبكراً**: القضاء على أخطاء `TypeError: undefined is not a function` و `cannot read property of null` الشهيرة قبل نشر التطبيق.
- **التوثيق الذاتي للكود**: تسهيل فهم وقراءة المشاريع الكبيرة والتعاون بين فرق التطوير.
- **إعادة هيكلة آمنة (Safe Refactoring)**: إعادة تسمية أو تعديل أي كائن أو خاصية وتحديث كافة مواضع استخدامها بنقرة واحدة دون خوف من كسر النظام.
