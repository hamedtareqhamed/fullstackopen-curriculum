سنتعرف في هذا القسم على أساسيات **الحاويات (Containers)**، وكيف تختلف عن الأجهزة الافتراضية التقليدية، وأساسيات استخدام **Docker CLI** لتشغيل وإدارة الحاويات.

---

### الفرق بين الحاوية (Container) والآلة الافتراضية (Virtual Machine)

- **الآلة الافتراضية (VM)**: تحاكي جهاز حاسوب كامل بما في ذلك نظام التشغيل الكامل (Guest OS) وطبقة Hypervisor، مما يجعلها ثقيلة وتستهلك قدراً كبيراً من الذاكرة والوقت للإقلاع.
- **الحاوية (Container)**: تتشارك نواة نظام التشغيل المضيف (Host OS Kernel) وتستخدم ميزات عزل مساحات الأسماء (Namespaces) ومجموعات التحكم (cgroups) في Linux، مما يجعلها خفيفة للغاية، وتبدأ في أجزاء من الثانية وتستهلك موارد ضئيلة جداً.

![مقارنة بين الآلات الافتراضية والحاويات](../../images/12/1.png)

### أوامر Docker الأساسية

- **تشغيل حاوية في الخلفية مع ربط المنافذ**:
  ```bash
  docker run -d -p 8080:80 --name my-web-server nginx
  ```
- **عرض الحاويات النشطة**:
  ```bash
  docker ps
  ```
- **عرض كافة الحاويات (بما فيها المتوقفة)**:
  ```bash
  docker ps -a
  ```
- **الدخول التفاعلي إلى داخل الحاوية**:
  ```bash
  docker exec -it my-web-server bash
  ```
- **إيقاف وحذف الحاوية**:
  ```bash
  docker stop my-web-server
  docker rm my-web-server
  ```
- **تمرير متغيرات البيئة**:
  ```bash
  docker run -e MESSAGE="Hello World" my-app
  ```

<h3>التمارين 12.1 - 12.5: أساسيات دوكر وتشغيل الحاويات</h3>

<h4>12.1: تشغيل أول حاوية (Running your first container)</h4>
شغل حاوية تفاعلية `ubuntu` واكتب بداخلها بعض الأوامر، وتأكد من فهم كيفية الخروج منها.

<h4>12.2: تشغيل الخادم وربط المنافذ (Port mapping)</h4>
شغل خادم ويب داخل حاوية مع ربط المنفذ الخارجي `8080` بالمنفذ الداخلي للحاوية، وافتحه في المتصفح `http://localhost:8080`.

<h4>12.3: تمرير متغيرات البيئة (Environment variables)</h4>
شغل تطبيقاً داخل حاوية يقرأ متغيراً بيئياً ويمرره عبر الخيار `-e`.

<h4>12.4: أوامر الإدارة الأساسية (Container management)</h4>
استخدم أوامر `docker logs` و `docker stop` و `docker rm` للتحكم في دورة حياة الحاويات وتنظيف النظام.

<h4>12.5: تشغيل حاوية Redis واستكشافها</h4>
شغل حاوية لقاعدة بيانات الذاكرة المؤقتة `redis`، وادخل إليها تفاعلياً عبر `docker exec -it <id> redis-cli` وجرب تخزين واسترجاع المفاتيح.
